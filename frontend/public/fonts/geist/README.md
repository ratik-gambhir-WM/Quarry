# Geist font assets

Geist Sans and Geist Mono 1.9.0, including upright and italic variable WOFF2 files.
Source: https://registry.npmjs.org/geist/-/geist-1.9.0.tgz (official `geist` package).
The archive was verified against its npm SHA-512 integrity metadata before extraction.

Licensed under the SIL Open Font License 1.1; see LICENSE.txt. Font binaries are
unmodified and renamed locally for URL-safe filenames. They are served from the
app origin for web and packaged desktop use. Only the upright Sans face is preloaded;
Mono and italics load when used. Update all faces and retain the license together.
